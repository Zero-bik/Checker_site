# Site Checker

Скрипт на Python для проверки доступности сайтов.

## Что делает
- Читает список сайтов из `sites.json`
- Отправляет GET-запросы с таймаутом в 3 секунды
- Ловит ошибки (Timeout, ConnectionError) и выводит статус в консоль

## Запуск
pip install requests
python3 checker_site.py

## Пример вывода
[ОК] Google сайт работает
[ОК] Яндекс сайт работает
Error Несуществующий сайт
Превышено время ожидания Тест Таймаута
